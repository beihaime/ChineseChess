# ChineseChess

A Chinese Chess (Xiangqi) game written in Java.

This project is currently under development.  
The goal is to build a complete Xiangqi game while learning Java, object-oriented design, game logic, and software architecture.

## Current Features

- Xiangqi board representation
- Initial board setup
- Console board rendering
- Piece movement
- Basic movement rules for:
  - Rook
  - Horse
  - Elephant
  - Advisor
  - General
  - Cannon
  - Pawn
- Board boundary validation
- Horse-leg blocking
- Elephant-eye blocking
- River and palace restrictions

## Planned Features

- Check detection
- Checkmate detection
- General-facing rule
- Turn system
- Move history
- Undo
- JavaFX GUI
- AI opponent

## Requirements

- Java 25
- Maven
